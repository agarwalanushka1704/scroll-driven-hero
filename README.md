# Scroll-Driven Hero Section Animation

A modern, premium hero section created as a frontend internship assignment. The project focuses on smooth entrance animations, scroll-based interactions, responsive design, and performance-friendly motion using GSAP.

## 🚀 Live Demo

[View Live Demo](https://agarwalanushka1704.github.io/scroll-driven-hero/)

## 📌 Project Overview

This project recreates a modern scroll-driven hero experience inspired by contemporary interactive web designs.

The main visual element responds directly to the user's scroll position, creating a smooth and interactive experience rather than using time-based autoplay animations.

## ✨ Features

- Premium dark-themed hero section
- Letter-spaced animated headline
- Smooth page-load animations
- Staggered statistics animation
- Scroll-driven car movement
- GSAP ScrollTrigger integration
- Smooth easing and interpolation
- Parallax-style background movement
- Animated speed lines
- Responsive design for desktop, tablet and mobile
- Performance-friendly transform-based animations
- Additional content section with feature animations

## 🛠️ Technologies Used
